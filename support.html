Quick Help

  • Photo Resize: Home → Photo Resize → Pick photo → Set KB range or exam preset (SSC, IBPS, Rail, UPSC) → Save
  • Passport Photo: Tools → Passport Photo → 35×45 mm or 2×2 inch, white/blue/red background
  • Signature: Tools → Signature → Draw or pick photo → Clean → Resize
  • PDF Tools: Image to PDF, Merge PDF, Compress PDF, PDF to Images — all on-device
  • CV Builder: Tools → CV Builder → Fill sections → Choose template → Export PDF (no watermark)
  • My Documents: Bottom bar → Documents → View, share, rename, delete, fingerprint lock
  • Sync with Drive: Profile → Sign in → Sync with Drive → Allow drive.file → Sync now → Files go to YOUR Drive folder "Docify"

FAQ

Do my documents go to your server?
No. Default 100% on-device. Only if you tap Sync, files go to YOUR Google Drive, not our server.

Why banner ad?
Free app, no paid features. Banner ads via AdMob support development.

Photo rejected by portal?
Check portal's exact KB, pixels, format. Use exam preset but verify on portal's checker.

How to delete Drive backup?
drive.google.com → Docify folder → Delete → Empty trash. Revoke at myaccount.google.com/permissions

Is Docify official SSC/IBPS/UPSC app?
No, preparation tool only.
