## ✨ Ki ache v1.2.0 te?

### 📸 Photo Tools
- **Photo Resize** — Exact KB limit (min–max), exam presets: SSC CGL/CHSL, IBPS PO/Clerk, RRB Rail, UPSC, WBCS, PSC, custom pixels, crop & compress
- **Passport Size Photo** — 35×45 mm / 2×2 inch, white/blue/red background, ek pata te multiple copy
- **Signature Resize** — Finger diye draw korun ba photo theke clean korun, background remove, KB te resize
- **Crop Image** — Free, Square, 4:3, 16:9, Passport ratios
- **JPG ↔ PNG** — Instant conversion, quality intact

### 📄 PDF Tools — Sob on-device!
- **Image to PDF** — Multiple images → 1 PDF
- **Merge PDF** — Multiple PDFs ek sathe
- **Compress PDF** — Upload er jonno size koman
- **PDF to Images** — Page gulo JPG hisebe extract
- **Document Scan** — Camera diye capture + auto crop, phone ei

### 📝 CV Builder — No Watermark!
- 10 professional templates: Modern, Minimalist, Executive, Creative, etc.
- Personal, Objective, Education, Experience, Skills, Declaration sections
- Photo add, template preview, fullscreen preview
- Export PDF — **kono Docify watermark nei** (v1.1.2 theke), direct send korar jonno ready
- Sob local, kono account lage na

### 📁 My Documents
- Sob file app er private folder e save
- View, Rename, Delete, Share (WhatsApp, Email, Drive, any app)
- **Fingerprint Lock** — Biometrics diye lock, Android check kore, amra fingerprint dekhi na
- **Stats:** Koto file ache Profile e dekhte parben

### 👤 Premium Profile — Notun Design! (v1.2.0 highlight)
- **App Header:** Logo, name, version (PackageInfo theke)
- **Account Card:** Guest vs Signed-in, Drive backup status, Sync now
- **Your Docify:** Documents count, Privacy 100%, Ads info
- **Quick Actions:** My Documents, Sync with Drive, Lock Documents
- **Preferences:** Language (EN + বাংলা coming soon), Automatic backup info, Fingerprint lock, Clear cache
- **Support & Feedback:** Rate on Play Store, Share app, Contact support, Report bug, What's new
- **Legal & About:** Privacy Policy, Terms, Data Deletion, Data Safety, About, Open Source Licenses, Ads, Web version — sob ek tap e
- **Footer:** Made with care in India 🇮🇳 + version + links

### ☁️ Optional Google Drive Sync — Apnar Drive e!
- **Guest-first:** Login chara full app kaj kore
- **Optional:** Profile → Sign in with Google → Sync with Drive → Allow `drive.file` scope only
- Files jay **apnar Google Drive er Docify folder e** — apnar account, apnar storage, amader server e na
- Folder structure `.docify-folders.json` hisebe save hoy, notun phone e restore korle folder same thakbe
- **Automatic backup** toggle (off by default) — app open/ resume e silent sync, max 15 min e ekbar, kokhono prompt kore na
- Sign out korle Drive er file delete hoy na — apni control koren

### 🔒 Private by Design
- Photos, signatures, PDFs, CV text **phone ei process** hoy
- Amader kono server nei je apnar document store kore
- My Documents fingerprint/face/PIN diye lock — Android check kore
- Ads: Google AdMob banner, kono interstitial/fullscreen ad nei
- Permissions: INTERNET (ads + optional Drive), CAMERA (scan only), WRITE_EXTERNAL_STORAGE maxSdk 29 (gallery save Android 10 and older) — **No broad storage, no location, no contacts, no SMS**
