## Quick help

### Photo resize
1. Home → Photo Resize
2. Pick photo from gallery
3. Set min–max KB (e.g., 20–50 KB) or choose exam preset (SSC, IBPS, Rail, UPSC)
4. Crop if needed → Save → File in My Documents

### Passport photo
1. Tools → Passport Photo
2. Pick photo, choose size 35×45 mm or 2×2 inch
3. Background white/blue/red
4. Save — multiple copies in one sheet

### Signature
1. Tools → Signature
2. Draw with finger or pick photo
3. Clean background, resize to KB
4. Save

### PDF tools
- Image to PDF: Select multiple images → Create PDF
- Merge PDF: Select PDFs → Merge
- Compress PDF: Select PDF → Choose quality → Compress
- PDF to images: Select PDF → Extract pages as JPG

### CV Builder
1. Tools → CV Builder
2. Fill Personal, Objective, Education, Experience, Skills, Declaration
3. Choose template (10 templates)
4. Preview → Export PDF → Saved in My Documents

### My Documents
- Bottom bar → Documents
- View, share (WhatsApp, Email, Drive), rename, delete
- Lock with fingerprint: Documents → Lock icon → Enable biometrics

### Sync with Google Drive (optional)
1. Profile → Sign in with Google
2. Profile → Sync with Drive → Allow drive.file
3. Sync now → Files go to YOUR Drive folder "Docify"
4. Restore: Sign in on new phone → Sync → Download
5. Automatic backup: Sync sheet → Toggle "Automatic backup" (off by default)

## FAQ

**Q: Do my documents go to your server?**
A: No. Default is 100% on-device. Only if you tap Sync, files go to YOUR Google Drive, not our server. We have no server.

**Q: App says "Sign-in not enabled on this build"**
A: This build has no google-services.json (guest mode). All tools still work. Release builds from Play Store have sign-in enabled.

**Q: Why banner ad?**
A: Docify is free, no paid features. Banner ads via AdMob support development. No interstitial/fullscreen ads.

**Q: Photo rejected by portal?**
A: Check portal's exact KB, pixels, format. Use Docify's exam preset but also verify on portal's checker. Some portals need 20–50 KB JPG, 200×230 px etc.

**Q: How to delete Drive backup?**
A: drive.google.com → Docify folder → Delete → Empty trash. Also revoke at myaccount.google.com/permissions.

**Q: How to delete account?**
A: Profile → Sign out or Delete Account, or email keshabsarkar2018@gmail.com with subject "Delete my Docify account".

**Q: Is Docify official app of SSC/IBPS/UPSC?**
A: No. It's a preparation tool, not official.
